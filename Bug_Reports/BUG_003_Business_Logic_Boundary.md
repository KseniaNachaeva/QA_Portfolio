# BUG-03: Ошибочное применение скидки -3% по полу для женщины 34 лет (вне диапазона 35–60 лет)

**Модуль:** Скоринг заявки (PUT /application/registration)  
**Критичность:** Major  
**Приоритет:** High  
**Тип тестирования:** Функциональное, граничные значения (Boundary Value Analysis)  

## Предусловия
- Микросервис Application запущен и доступен по адресу http://localhost:8080
- БД доступна, микросервисы Deal и Conveyor доступны
- Выполнен вызов POST /application для клиентки возрастом 34 года (дата рождения рассчитана так, чтобы на момент теста было 34 года)
- Выбрано предложение №1 и выполнен вызов POST /application/apply (статус = APPROVED)

## Шаги воспроизведения

| № | Шаг | Данные | Ожидаемый результат |
|---|-----|--------|---------------------|
| 1 | Выполнить вызов PUT /application/registration/{applicationId} с указанием пола | **URL:** http://localhost:8080/application/registration/{applicationId}**Body:**```{  "gender": "FEMALE",  "maritalStatus": "SINGLE",  "dependentAmount": 0,  "passportIssueDate": "2010-01-01",  "passportIssueBranch": "Department 5B",  "employment": {    "employmentStatus": "EMPLOYED",    "employerINN": "123456789012",    "salary": 50000,    "position": "WORKER",    "workExperienceTotal": 36,    "workExperienceCurrent": 12  },  "account": "11223344556677889900"}``` | Метод вызван, HTTP 200 OK |
| 2 | Проверить рассчитанную ставку в БД | **SQL:**```SELECT rate FROM credit WHERE application_id = <applicationId>``` | `rate` = 15.0 (базовая ставка, корректировка по полу не применяется, так как возраст < 35 лет) |

## Фактический результат
Тест не пройден. `rate` = 12.0 (скидка -3% применена ошибочно, несмотря на то, что возраст 34 года не попадает в диапазон 35–60 лет).

## Примечание
**Бизнес-ценность:** Ошибка в граничных условиях приводит к систематическому недовыполнению плановой доходности по кредитному портфелю. Каждое такое одобрение генерирует убыток для банка в виде недополученных процентов на протяжении всего срока кредита.
