## Что демонстрирует это портфолио

В этой работе я показала свой подход к тестированию микросервисной архитектуры на примере системы кредитования. Здесь можно увидеть:

**Работа с API:**
- Уверенное владение Postman и Swagger для тестирования REST API
- Понимание HTTP-методов, кодов ответов и структуры JSON
- Умение составлять комплексные наборы запросов для проверки бизнес-логики

**Работа с данными:**
- Написание SQL-запросов разной сложности (от простых SELECT до JOIN и подзапросов)
- Проверка целостности данных между связанными таблицами
- Валидация корректности сохранения и обновления информации

**Понимание архитектуры:**
- Как взаимодействуют микросервисы через HTTP и асинхронные сообщения (Kafka)
- Отслеживание полного пути запроса через несколько сервисов
- Проверка корректности обмена данными между компонентами системы

**Security-мышление:**
- Тестирование на уязвимости (SQL-инъекции, XSS)
- Проверка валидации входных данных
- Выявление потенциальных проблем с целостностью данных

## О проекте

Это портфолио — результат моей работы над учебным проектом NeoFlex и самостоятельного изучения темы. Мне было важно не просто «проставить галочки» в чек-листах, а действительно разобраться, как работает система изнутри, найти слабые места и показать, как их можно обнаружить до того, как они станут проблемой для пользователей.

Здесь собраны реальные примеры тестовой документации: от простых позитивных сценариев до сложных кейсов с проверкой граничных значений и безопасности.

В рамках этого проекта мной было разработано более 160 тест-кейсов, выявлено и оформлено 18 баг-репортов, а также созданы чек-листы для smoke-тестирования.
