# TC-POS-20: Проверка полного цикла взаимодействия Application → Deal → Conveyor → Deal → Application

**Модуль:** Создание заявки (POST /application)  
**Приоритет:** High  
**Тип тестирования:** Интеграционное, функциональное  

## Предусловия
- Микросервис Application запущен и доступен по адресу http://localhost:8080
- БД доступна
- Микросервисы Deal, Conveyor доступны

Тест пройден успешно

## Примечание
Этот тест проверяет **полный цикл взаимодействия** между микросервисами:
1. Application получает запрос от клиента
2. Application вызывает Deal
3. Deal вызывает Conveyor для расчета предложений
4. Conveyor возвращает результат в Deal
5. Deal возвращает результат в Application
6. Application сохраняет данные в БД и возвращает ответ клиенту

Тест подтверждает корректную работу **всей цепочки микросервисов**.
