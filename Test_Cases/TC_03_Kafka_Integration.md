# TC-4.4.2-POS-12: Проверка Kafka-взаимодействия между МС Deal и МС Dossier

**Модуль:** Получение выбранного кредитного предложения (POST /application/apply)  
**Приоритет:** High  
**Тип тестирования:** Интеграционное, функциональное  

## Предусловия
- Микросервис Application запущен и доступен по адресу http://localhost:8080
- БД доступна
- Микросервисы Deal и Dossier доступны
- Kafka доступна, консьюмер для топика finish-registration настроен
- Выполнен вызов метода POST /application (4.4.1) с валидными данными
- Получен HTTP 200 OK, сохранены applicationId и список из 4 кредитных предложений

## Фактический результат

## Примечание
Этот тест проверяет **интеграцию через Kafka**:
1. МС Deal отправляет сообщение EmailMessage в Kafka-топик
2. МС Dossier получает сообщение из Kafka
3. МС Dossier формирует и отправляет письмо клиенту

Тест подтверждает корректную работу **асинхронного взаимодействия** между микросервисами через брокер сообщений Kafka.
