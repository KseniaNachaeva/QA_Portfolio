# TC-NEG-17: Получение ошибки при создании заявки с возрастом 17 лет (меньше минимального)

**Модуль:** Создание заявки (POST /application)  
**Приоритет:** High  
**Тип тестирования:** Негативное, граничные значения  

## Предусловия
- Микросервис Application запущен и доступен по адресу http://localhost:8080
- БД доступна
- Микросервис Deal доступен

## Шаги воспроизведения

| № | Шаг | Данные | Ожидаемый результат |
|---|-----|--------|---------------------|
| 1 | Выполнить вызов метода POST /application МС Application | **URL:** http://localhost:8080/application**Body:**```{  "amount": 50000,  "term": 12,  "firstName": "Ivan",  "lastName": "Ivanov",  "middleName": "Ivanovich",  "email": "neg17@test.com",  "birthdate": "2009-09-03",  "passportSeries": "1234",  "passportNumber": "123456"}```**Примечание:** возраст 17 лет (на 03.09.2026) | Метод вызван |
| 1.1 | Проверить наличие сообщения о вызове МС Deal в логах МС Application | — | **Сообщение о вызове МС Deal ОТСУТСТВУЕТ в логах** |
| 2а | Убедиться, что данные клиента не сохранены в БД | **SQL:**```SELECT * FROM client WHERE email = 'neg17@test.com'``` | **Запись НЕ найдена** |
| 2а.1 | Убедиться, что параметры кредита не сохранены в таблице credit | **SQL:**```SELECT * FROM credit WHERE application_id = (  SELECT id FROM application   WHERE client_id = (    SELECT id FROM client     WHERE email = 'neg17@test.com'  ))``` | **Запись НЕ найдена** |
| 3б | Убедиться, что вернулся ответ с ошибкой и кодом 500 | — | **HTTP статус 500**, тело ответа содержит сообщение об ошибке ERR_1 |
| 4 | Проверить наличие информации об ошибке в логах | — | В логах МС Application присутствует stack trace, указывающий на **недопустимый возраст клиента** |

## Фактический результат
Тест пройден успешно

## Примечание
Этот тест проверяет **граничное значение возраста** (минимальный возраст = 18 лет).

При возрасте 17 лет система должна:
- НЕ вызывать микросервис Deal
- НЕ сохранять данные в БД
- Вернуть ошибку HTTP 500 с кодом ERR_1
- Записать ошибку в логи

Тест подтверждает корректную работу **валидации возраста** на раннем этапе обработки запроса.
